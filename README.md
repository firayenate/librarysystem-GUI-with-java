# Library Management System GUI (Java)

A simple Java GUI-based Library Management System developed using Java OOP concepts.
This project provides user authentication and dashboard interfaces for managing library operations.

## Features

* User Login System
* User Registration
* Admin Dashboard
* User Dashboard
* Java Swing GUI
* Object-Oriented Programming (OOP)

## Technologies Used

* Java
* Java Swing
* OOP Concepts
* Git & GitHub

## Project Structure

```text
AdminDashboard.java
LoginFrame.java
RegisterFrame.java
UserDashboard.java
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/firayenate/librarysystem-GUI-with-java.git
```

2. Open the project in your Java IDE

   * NetBeans
   * IntelliJ IDEA
   * Eclipse

3. Compile and run the project
